PAGINA DE VENTA DE ROKUSHO
==========================

Este repositorio publica la pagina de venta mediante GitHub Pages.

Contenido de esta rama:
  index.html                    la pagina de venta
  muestra/ejemplo-informe.html  informe completo de ejemplo

Para actualizar la pagina:
  editar docs/venta.html en la rama master, copiar aqui como index.html
  y hacer commit en esta rama.

Para volver a la rama de trabajo:
  git checkout master
